次のステップ

  1. 上の「更新を確認」で GitHub 上の最新状態を取得する
  2. 未分類のリポジトリは custom-descriptions.json の courses / tools に追加する
  3. 公開したいリポジトリは private を解除してから python scripts/fetch_repositories.py で repositories.json を更新する
  4. 変更をコミット・プッシュすると公開ページに反映される
